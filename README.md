# Играем!

Офлайн-игры для ребёнка 4 лет и взрослого. Приложение не заменяет игру, а подсказывает,
во что играть: телефон обычно лежит в руках взрослого, а ребёнок отвечает словами.

Ничего не грузится из сети: весь контент внутри приложения. Аккаунтов, сохранений
и бэкенда нет.

## Игры

**Смотри и называй** — экран показываем ребёнку:

- Марки машин, Угадай героя (появляются, когда добавишь картинки — см. ниже)
- Сколько? — считаем предметы вслух
- Запомни и назови — картинки исчезают через несколько секунд
- Что изменилось? — показали, спрятали, показали снова, но одна картинка другая

**Слушай и отвечай** — экран нужен только взрослому:

- Слово на букву — «назови животное на букву Б»
- Загадки — по звуку, по приметам, по назначению
- Что лишнее? — четыре слова, и главное здесь «почему»
- Найди пару — из шести слов найти два подходящих
- Что будет дальше? — простые последовательности

**Играем вместе**:

- Кто я? — описываем, не называя
- Покажи без слов — пантомима, роли меняются
- Объясни слово — ребёнок рассказывает, взрослый помогает вопросами
- Придумай историю — три случайные картинки
- Кто быстрее назовёт — таймер и тема

Оценивает всегда взрослый кнопками «Угадал / Мимо»: никакой автоматической проверки,
ребёнку не нужно ничего нажимать и никуда вести пальцем.

## Как поставить на телефон

Каждый пуш в `master` собирает APK и выкладывает его в раздел Releases. Постоянная ссылка
на самую свежую сборку:

```
https://github.com/Huga55/smarty-games/releases/latest/download/igraem.apk
```

На телефоне: открыть ссылку в браузере, скачать файл, открыть его и разрешить установку
из этого источника. Обновление ставится поверх — данные и настройки сохраняются.

Первый раз перед сборкой нужно один раз положить ключ подписи в секреты репозитория
(значения лежат в локальной папке `secrets/`, в git она не попадает):

| Секрет              | Что положить                                  |
| ------------------- | --------------------------------------------- |
| `KEYSTORE_BASE64`   | содержимое `secrets/keystore.base64`          |
| `KEYSTORE_PASSWORD` | пароль из `secrets/keystore-info.txt`         |
| `KEY_PASSWORD`      | тот же пароль                                 |
| `KEY_ALIAS`         | `igraem`                                      |

Без секретов сборка тоже пройдёт, но APK будет отладочным, и обновиться поверх него
не получится — придётся удалять приложение и ставить заново.

## Как добавить картинки марок и героев

Положить файлы в папки — и всё:

- `src/assets/cars/` — логотипы марок: `БМВ.png`, `Тойота.svg`, `Лада.webp`
- `src/assets/heroes/` — герои: `Лунтик.png`, `Чебурашка.jpg`

Имя файла становится ответом для взрослого. Как только в папке появится хотя бы один
файл, игра сама появится в меню.

## Как добавить свой контент

Почти всё живёт в `src/content/`:

- `items.ts` — главный справочник объектов. Один объект с эмодзи, категориями и приметами
  сразу попадает в десяток игр: в загадки, «Кто я?», «Что лишнее», «Сколько?» и остальные.
- `riddles.ts` — загадки и последовательности, которые нужно придумывать руками
- `odd.ts` — наборы «Что лишнее?» с несколькими правильными ответами
- `words.ts` — буквы, категории слов, темы для таймера, задания для пантомимы

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run dev:lan    # то же, но доступно с телефона по локальной сети
npm run typecheck
npm run build
npm run icons      # перерисовать иконки и экран запуска
```

Сборка APK локально не нужна и не настроена: этим занимается GitHub Actions
(`.github/workflows/android.yml`), где Android SDK уже установлен.

## Стек

Vite, React, TypeScript, Capacitor. Никаких сетевых запросов, никакой аналитики,
никаких разрешений кроме доступа в интернет, который требует сам WebView.
